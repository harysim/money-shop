# متجر النقود (Money Shop)

تطبيق ويب تعليمي بصوت عربي لتدريب طالبات المرحلة التأهيلية على استخدام النقود في البيع والشراء.
في كل لعبة تشاهد الطالبة «نورة» وهي تؤدي المهمة في متجر، ثم تؤديها بنفسها (نمذجة بالفيديو).

الألعاب: جدار النقود، ادفعي السعر (سحب النقود إلى الطاولة)، هل يكفي المبلغ؟، كم الباقي؟ (العد التصاعدي)، رحلة التسوق.

- `index.html`: التطبيق
- `audio/`: الملفات الصوتية (صوت عربي سعودي) مع `manifest.json`
- صفحة المعلمة (رابط أسفل الصفحة): الإعدادات ونص التسجيل الصوتي

يعمل على الجوال والجهاز اللوحي دون تسجيل دخول، ولا يجمع أي بيانات عن الطالبات (النجوم والإعدادات تُحفظ على الجهاز فقط).
