# متجر النقود (Money Shop)

تطبيق ويب تعليمي بصوت عربي لتدريب طالبات المرحلة التأهيلية على استخدام النقود في البيع والشراء:
التعرف على النقود، تكوين المبلغ، هل يكفي المبلغ؟، حساب الباقي بالعد التصاعدي.

- `index.html`: التطبيق
- `audio/`: الملفات الصوتية (صوت عربي سعودي)، مع `manifest.json`

يعمل على الجوال والجهاز اللوحي دون تسجيل دخول، ولا يجمع أي بيانات عن الطالبات (النجوم تُحفظ على الجهاز فقط).
